## A explicação rápida (≈ as duas coisas do dia)

**1) Listar — GET** (você já viu, é só pra ter o que mostrar)
```js
$.getJSON(API + '?aluno_id=' + ALUNO_ID, function (tarefas) {
  console.log(tarefas);   // array de tarefas suas
});
```

**2) Criar — POST** (o assunto novo)
```js
$('#form').on('submit', function (e) {
  e.preventDefault();                          // trava o reload da página
  var titulo = $('#titulo').val().trim();
  if (titulo === '') return;                   // não manda vazio
  $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }, function () {
    $('#titulo').val('').focus();              // limpa e volta o foco
    listar();                                  // recarrega a lista
  });
});
```

> 🧠 **`e.preventDefault()` é o herói da aula.** Sem ele o `<form>` recarrega a página inteira e o AJAX nem roda. O padrão de ouro é sempre: **criar → recarregar a lista**.

Para tratar erro (servidor real falha!), use o formato com `.done`/`.fail`:
```js
$.post(API, { aluno_id: ALUNO_ID, titulo: titulo })
  .done(function (criada) { listar(); })
  .fail(function (xhr)   { alert('Deu ruim 😕 (' + xhr.status + ')'); });
```

**É isso. Agora é com vocês.** ⬇️
