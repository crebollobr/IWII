## Setup obrigatório — seu `aluno_id` (faça UMA vez)

A API é compartilhada pela turma toda. Para suas tarefas não se misturarem com as dos colegas, **cada aluno escolhe um identificador único** e usa sempre o mesmo. A gente guarda no `localStorage` do navegador (uma caixinha que lembra das coisas mesmo depois de fechar o navegador), uma vez só.

Crie `lab23/setup.html`, abra no navegador, digite seu id e clique salvar:

```html
<!DOCTYPE html>
<html lang="pt-br"><head><meta charset="utf-8"><title>Setup</title>
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script></head>
<body>
  <h1>Configuração do aluno</h1>
  <input id="id" placeholder="ex: ana_souza_42">
  <button id="salvar">Salvar</button>
  <p id="msg"></p>
  <script>
    $('#salvar').on('click', function () {
      var id = $('#id').val().trim();
      if (id === '') { $('#msg').text('Digite algo!'); return; }
      localStorage.setItem('aluno_id', id);   // grava no navegador
      $('#msg').text('Salvo! Seu aluno_id é: ' + id);
    });
  </script>
</body></html>
```

Feito isso, **todo** arquivo da aula vai ler esse id assim:

```js
var ALUNO_ID = localStorage.getItem('aluno_id');   // lê o que você salvou
```

# Parte 1 — Relembrando o jQuery (com exemplos)

Antes do servidor, 4 ferramentas que você já viu. Cada uma com exemplo pronto.

### a) Selecionar e mudar conteúdo
`$('#id')` pega o elemento; `.text()` troca o texto dentro dele.
```js
$('#titulo').text('Olá, turma!');   // o elemento #titulo passa a mostrar "Olá, turma!"
```

### b) Reagir a clique — `.on('click', ...)`
```js
$('#botao').on('click', function () {
  $('#saida').text('Você clicou!');
});
```

### c) Reagir enquanto digita — `.on('input', ...)`
`.val()` lê o que está escrito num campo.
```js
$('#campo').on('input', function () {
  $('#eco').text( $('#campo').val() );   // mostra ao vivo o que você digita
});
```

### d) Sortear um item de uma lista
`Math.random()` dá um número entre 0 e 1; com `Math.floor` viramos um índice do array.
```js
var emojis = ['🔥', '💯', '🚀', '😎'];
var sorteado = emojis[ Math.floor(Math.random() * emojis.length) ];
```

### e) Ligar/desligar uma classe CSS — `.toggleClass(...)`
```js
$('body').toggleClass('escuro');   // adiciona a classe se não tem, tira se tem
```

# Parte 2 — Ler do servidor: `$.getJSON`

Até agora os dados estavam no seu próprio arquivo. Agora eles moram **noutro computador** e você pega pela internet com **`$.getJSON`**:

```js
$.getJSON(API + '?aluno_id=' + ALUNO_ID, function (tarefas) {
  console.log(tarefas);   // 'tarefas' é um array com as suas tarefas
});
```

> 🧠 **Isso é assíncrono.** O servidor demora um tiquinho pra responder. Por isso você só mexe nos dados **dentro** daquela função (o *callback*). Na primeira vez a lista vem **vazia** — normal, você ainda não criou nada (a gente cria na Parte 3).

### Percorrer o array e montar a lista — `$.each` + criar `<li>`
`$.each(array, fn)` roda a função uma vez para cada item. `$('<li>')` cria um `<li>` novo; `.appendTo(...)` coloca ele dentro de algo.

**Exemplo resolvido** (listar os títulos numa `<ul id="lista">`):
```js
function listar() {
  $.getJSON(API + '?aluno_id=' + ALUNO_ID, function (tarefas) {
    $('#lista').empty();                          // limpa a lista antes de redesenhar
    $.each(tarefas, function (i, t) {             // t = uma tarefa
      $('<li>').text(t.titulo).appendTo('#lista');
    });
  });
}
listar();
```

> `tarefas.length` dá a **quantidade** de itens do array. Útil pra contar.

# Parte 3 — Criar no servidor: `$.post`

Para **gravar** no servidor, use **`$.post`**. A API precisa de dois campos: `aluno_id` e `titulo`.

```js
$.post(API, { aluno_id: ALUNO_ID, titulo: 'Estudar jQuery' }, function (criada) {
  console.log('Criei a tarefa de id', criada.id);
});
```

### O padrão de ouro: **formulário → criar → recarregar**
Num `<form>`, quando você envia, o navegador **recarrega a página** por padrão — e seu AJAX nem roda. Para impedir isso usamos `e.preventDefault()`. `.val()` lê o campo; `.val('')` limpa; `.focus()` devolve o cursor.

**Exemplo resolvido:**
```js
$('#form').on('submit', function (e) {
  e.preventDefault();                          // 🦸 impede o reload da página
  var titulo = $('#titulo').val().trim();
  if (titulo === '') return;                   // não manda vazio
  $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }, function () {
    $('#titulo').val('').focus();              // limpa o campo e volta o cursor
    listar();                                  // redesenha a lista
  });
});
```

> 🚫 **Evitar clique-duplo:** `.prop('disabled', true)` desliga o botão; `.prop('disabled', false)` religa.

# Parte 4 — Quando dá erro (e validação)

Servidor real **falha**: internet cai, dado vem errado. Em vez do callback simples, use o formato com **`.done()` / `.fail()` / `.always()`**:

```js
$.post(API, { aluno_id: ALUNO_ID, titulo: titulo })
  .done(function (criada) { listar(); })                       // deu certo
  .fail(function (xhr)   { alert('Deu ruim 😕 (' + xhr.status + ')'); })  // deu erro
  .always(function ()    { $('#enviar').prop('disabled', false); });      // sempre roda
```

> 🧪 `xhr.status` é o código do erro (400 = pedido inválido, 500 = problema no servidor, 0 = sem internet).

### Validação visual (sem `alert` chato)
A classe `.erro` deixa o campo com borda vermelha. Tire ela assim que o usuário digitar de novo:
```js
if ($('#titulo').val().trim() === '') {
  $('#titulo').addClass('erro').focus();
  return;
}
$('#titulo').removeClass('erro');
```
```js
$('#titulo').on('input', function () { $('#titulo').removeClass('erro'); });
```

### Feedback que aparece e some — `.fadeIn` / `.fadeOut` + `setTimeout`
```js
$('#aviso').text('Salvo ✅').fadeIn();
setTimeout(function () { $('#aviso').fadeOut(); }, 2000);   // some depois de 2s
```
