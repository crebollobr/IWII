# 📚 PARTE A — TEORIA

## A.0 — O que é uma SPA (e o que é "hidratar")

**SPA = Single Page Application** (aplicação de página única). O site **carrega uma vez só**. Daí pra frente, quem troca o que aparece na tela é o **JavaScript**: ele pede dados ao servidor (AJAX) e atualiza só os pedaços que mudaram. A página **nunca recarrega**. Gmail, Instagram e Trello são assim — você clica e o conteúdo muda na hora, sem aquele "branco" de página recarregando.

> 💧 **Hidratar.** O HTML chega "seco" — é só o esqueleto: campos vazios, tabela sem linhas. O JavaScript vai ao servidor, traz os dados e **molha** esse esqueleto, preenchendo os campos. Esse ato de encher a tela vazia com dados reais é o que chamamos de **hidratar**.

Hoje você constrói o coração de qualquer SPA: o **CRUD**.

| Letra | Ação | Comando | Aula |
|---|---|---|---|
| **C** | Create — cadastrar | `$.post` | **hoje** |
| **R** | Read — ler/listar | `$.getJSON` | **hoje** |
| **U** | Update — editar | `$.ajax` PUT | próxima |
| **D** | Delete — apagar | `$.ajax` DELETE | próxima |

## A.2 — Read: ler do servidor com `$.getJSON`

Pra **buscar** a lista de matrículas (em JSON):
```js
$.getJSON(API + '?recurso=matriculas', function (lista) {
  // 'lista' é um array de matrículas; só existe AQUI dentro
  console.log(lista);
});
```

> 🍽️ **É assíncrono** (o garçom da aula passada): o servidor demora um tiquinho. Por isso você só mexe nos dados **dentro** da função (o *callback*). Na primeira vez a lista vem vazia — você ainda não cadastrou ninguém.

**Exemplo resolvido — hidratar um `<ul>` com os nomes:**
```js
function carregar() {
  $.getJSON(API + '?recurso=matriculas', function (lista) {
    var $ul = $('#lista');
    $ul.empty();                                  // limpa antes de redesenhar
    $.each(lista, function (i, m) {               // m = uma matrícula
      $('<li>').text(m.nome).appendTo($ul);       // .text() = seguro contra XSS
    });
  });
}
carregar();
```
- **`.empty()`** esvazia antes (senão duplica a cada carregamento).
- **`$.each(array, fn)`** roda a função uma vez por item.
- **`.text(...)`** (e nunca `.html(...)`) pra dado vindo do servidor/usuário — evita que um `<script>` no nome execute na página (isso se chama **XSS**; vocês viram em 29/05).

## A.3 — Hidratar um **formulário** (a base do nosso app)

Nosso projeto não mostra uma lista solta: mostra **uma matrícula por vez** num formulário, e você navega entre elas (Anterior / Próximo) — como um app de cadastro real.

A ideia: guardamos a lista numa variável e um índice de "onde estou". A função `mostrar()` pega o registro daquele índice e **preenche os campos**:

```js
var registros = [];   // a lista que veio do servidor
var pos = 0;          // qual estou vendo

function mostrar() {
  if (registros.length === 0) return;            // nada pra mostrar ainda
  var m = registros[pos];
  $('#id').val(m.id);                             // campo escondido guarda o id
  $('#nome').val(m.nome);
  $('#cpf').val(m.cpf);
  $('#curso').val(m.curso);
  $('#email').val(m.email);
  $('#ativo').prop('checked', m.ativo == 1);     // checkbox: marcado se ativo
  $('#pos').text(pos + 1);                        // "registro 3 de 12"
  $('#total').text(registros.length);
}
```

> 🧠 **`.val()` é via de mão dupla:** `.val()` (sem nada) **lê** o campo; `.val('algo')` **escreve** no campo. Pra checkbox use `.prop('checked', true/false)` pra marcar e `.is(':checked')` pra ler.

Navegar é só mudar o `pos` e chamar `mostrar()`:
```js
$('#proximo').on('click', function () {
  if (pos < registros.length - 1) { pos++; mostrar(); }
});
$('#anterior').on('click', function () {
  if (pos > 0) { pos--; mostrar(); }
});
```

## A.4 — Create: cadastrar com `$.post`

Pra **gravar** um registro novo, mandamos os campos com `$.post`:
```js
$.post(API + '?recurso=matriculas', {
  nome: 'Ana', cpf: '111', curso: 'Informática', email: 'ana@x.com', ativo: 1
})
.done(function (criada) { console.log('Cadastrei id', criada.id); })
.fail(function (xhr)   { alert('Erro (' + xhr.status + ')'); });
```

O **padrão de ouro** continua: **cadastrar → recarregar a lista**. E como estamos num formulário, lemos os valores com `.val()`:
```js
function salvar() {
  var dados = {
    nome:  $('#nome').val().trim(),
    cpf:   $('#cpf').val().trim(),
    curso: $('#curso').val().trim(),
    email: $('#email').val().trim(),
    ativo: $('#ativo').is(':checked') ? 1 : 0
  };
  $.post(API + '?recurso=matriculas', dados)
    .done(function () { carregar(); })           // recarrega a lista
    .fail(function (xhr) { alert('Não salvou (' + xhr.status + ')'); });
}
```

> 🆕 **Botão "Novo".** Pra cadastrar, primeiro a gente **limpa o formulário** (sem id). Quando o campo `#id` está vazio, "Salvar" significa **criar** (Create). Na próxima aula, quando tiver id, "Salvar" vai significar **editar** (Update) — é o "salvar inteligente".

## A.5 — Tratamento de erro e validação (boas práticas)

Servidor real **falha**. Sempre encadeie `.done / .fail / .always`:
```js
$.post(API + '?recurso=matriculas', dados)
  .done(function (criada) { carregar(); mostrarAviso('Salvo ✅'); })
  .fail(function (xhr)   { mostrarAviso('Erro ' + xhr.status + ' 😕'); })
  .always(function ()    { $('#salvar').prop('disabled', false); });
```
- **`.done`** = deu certo · **`.fail`** = deu erro (`xhr.status`: 400 inválido, 500 servidor, 0 sem internet) · **`.always`** = roda sempre (bom pra religar botão).

**Validação antes de enviar** (não mande lixo pro servidor):
```js
if ($('#nome').val().trim() === '') {
  $('#nome').addClass('erro').focus();    // borda vermelha
  return;                                  // e NÃO envia
}
$('#nome').removeClass('erro');
```

## A.6 — Boas práticas de jQuery (vamos usar a aula toda)

1. **Separe servidor de tela.** Junte as chamadas num objeto `API` (a "camada de dados"); o resto do código fica limpo:
   ```js
   var Matriculas = {
     listar: function ()        { return $.getJSON(API + '?recurso=matriculas'); },
     criar:  function (dados)   { return $.post(API + '?recurso=matriculas', dados); }
   };
   // uso: Matriculas.listar().done(render);   Matriculas.criar(dados).done(carregar);
   ```
2. **Cache de seletor.** Buscar o mesmo elemento toda hora é desperdício. Guarde:
   ```js
   var $nome = $('#nome'), $lista = $('#lista');   // busca uma vez, usa sempre
   ```
3. **`.text()` pra dado de usuário** (anti-XSS), nunca `.html()`.
4. **Funções retornam a promise** (`return $.getJSON(...)`) pra dar pra encadear `.done/.fail`.
5. **Trate erro sempre** — nada de falhar calado.

### `desafio1-agenda-ler.html` — 💧 Hidratar a grade
**O que fazer:** carregue o recurso `agenda` e escreva o `texto` de cada tarefa na célula certa (a célula tem `data-dia` e `data-hora`).
```html
<!DOCTYPE html><html lang="pt-br"><head><meta charset="utf-8"><title>Agenda</title>
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<style>
  table{border-collapse:collapse;font-family:system-ui} td,th{border:1px solid #ccc;width:90px;height:34px;text-align:center;font-size:13px}
  th{background:#f4f4f4} td:hover{background:#eef;cursor:pointer}
</style></head><body>
  <h1>🗓️ Minha semana</h1>
  <table id="grade"></table>
  <script>
    var API = 'https://curso.chr.eti.br/ajax/matricula05.php';
    var DIAS = ['Seg','Ter','Qua','Qui','Sex','Sáb','Dom'];
    var HORAS = [];
    for (var h = 6; h <= 24; h++) HORAS.push((h % 24 < 10 ? '0' : '') + (h % 24) + ':00'); // 06:00..00:00

    function montarGrade() {                         // monta a grade VAZIA (pronto)
      var $g = $('#grade');
      var $head = $('<tr>').append($('<th>').text('hora'));
      $.each(DIAS, function (i, d) { $('<th>').text(d).appendTo($head); });
      $g.append($head);
      $.each(HORAS, function (i, hora) {
        var $tr = $('<tr>').append($('<th>').text(hora));
        $.each(DIAS, function (j, dia) {
          $('<td>').attr('data-dia', dia).attr('data-hora', hora).appendTo($tr);
        });
        $g.append($tr);
      });
    }

    function celula(dia, hora) {                      // acha a <td> de um dia/hora
      return $('td[data-dia="' + dia + '"][data-hora="' + hora + '"]');
    }

    $(function () {
      montarGrade();
      // ✏️ SEU CÓDIGO AQUI: getJSON no recurso agenda → para cada tarefa, celula(t.dia,t.hora).text(t.texto)
    });
  </script>
</body></html>
```
**Resultado esperado:** as tarefas que existem no servidor aparecem nas células certas.
**💡 Dica:** `$.getJSON(API + '?recurso=agenda', function (tarefas) { $.each(tarefas, function (i, t) { celula(t.dia, t.hora).text(t.texto); }); });`

### `desafio2-agenda-criar.html` — ✍️ Clicar na célula e escrever (com animação)
**O que fazer:** parta do `desafio1`. Ao **clicar numa célula vazia**, mostre um `<input>` ali (com animação), e ao **sair** (blur) **ou** apertar **Enter**, **cadastre** a tarefa (POST no recurso `agenda` com `dia`, `hora`, `texto`) e escreva o texto na célula.
**HTML:** _(parta do `desafio1-agenda-ler.html`)_
**Resultado esperado:** clicou numa célula vazia → surge um campo → digitou "Academia" + Enter → fica gravado (recarregue a página: continua lá).
**💡 Dica:**
```js
$('#grade').on('click', 'td', function () {
  var $td = $(this);
  if ($td.find('input').length) return;            // já está editando
  var dia = $td.data('dia'), hora = $td.data('hora');
  var $inp = $('<input>').css('width','80px').hide();
  $td.empty().append($inp);
  $inp.fadeIn(150).focus();                          // animação de entrada
  function salvar() {
    var texto = $inp.val().trim();
    if (texto === '') { $td.empty(); return; }
    $.post(API + '?recurso=agenda', { dia: dia, hora: hora, texto: texto })
      .done(function () { $td.text(texto); })
      .fail(function () { alert('Erro ao salvar'); $td.empty(); });
  }
  $inp.on('blur', salvar);
  $inp.on('keydown', function (e) { if (e.key === 'Enter') $inp.blur(); });
});
```
