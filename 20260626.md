# Parte 1 — O comando completo: `$.ajax`

## Explicação

Na Aula 3 você usou `$.getJSON` (pra ler) e `$.post` (pra criar). O que talvez você não saiba: esses dois são só **atalhos**. Por baixo do capô, os dois chamam o **mesmo motor**, o **`$.ajax`** — só que já com tudo configurado pro caso comum.

> 🚗 **Analogia do carro automático vs. manual.** `$.getJSON` é o câmbio automático: simples, faz o trabalho. `$.ajax` é o câmbio manual: dá mais trabalho, mas **você escolhe a marcha**. E pra editar (PUT) e apagar (DELETE) a gente **precisa** escolher a marcha — porque essas operações usam "métodos" diferentes que o atalho não oferece.

Todo pedido HTTP tem um **método** (o tipo de ação): **GET** (ler), **POST** (criar), **PUT** (atualizar), **DELETE** (apagar). O `$.ajax` recebe um objeto descrevendo o pedido:

```js
$.ajax({
  url: API + '?aluno_id=' + ALUNO_ID,  // pra onde vai
  method: 'GET',                       // qual ação (GET/POST/PUT/DELETE)
  dataType: 'json'                     // "me devolva já convertido de JSON"
})
.done(function (resposta) { /* deu certo */ })
.fail(function (xhr)      { /* deu erro  */ });
```

## Exemplo resolvido (comentado)

Listar com `$.ajax` — faz exatamente o que o `$.getJSON` fazia, mas mostrando o **id** de cada tarefa (vamos precisar dele o tempo todo hoje, pra dizer ao servidor *qual* tarefa editar/apagar):

```js
function listar() {
  $.ajax({ url: API + '?aluno_id=' + ALUNO_ID, method: 'GET', dataType: 'json' })
    .done(function (tarefas) {
      $('#lista').empty();
      $.each(tarefas, function (i, t) {
        $('<li>').text('[' + t.id + '] ' + t.titulo).appendTo('#lista');  // mostra o id
      });
    })
    .fail(function (xhr) { alert('Erro ao listar (' + xhr.status + ')'); });
}
```

# Parte 2 — Editar uma tarefa: **PUT**

## Explicação

**PUT** serve pra **atualizar algo que já existe**. Diferente do POST (que cria do zero), o PUT precisa dizer **qual** registro mexer. Na nossa API, três regras:

1. **Qual** tarefa? O **id** vai na URL: `api.php?id=7`.
2. **Como** mandar os dados? Como **JSON** no corpo do pedido. Isso exige duas coisas juntas:
   - `contentType: 'application/json'` → avisa o servidor "estou te mandando JSON".
   - `JSON.stringify({...})` → transforma seu objeto JavaScript em **texto** JSON pra viajar pela rede.
3. **O que** mandar? O `aluno_id` (pra provar que a tarefa é sua) + o campo que mudou. A API atualiza **só o que você enviar** — manda só o `titulo` e o resto fica como estava.

> 🧠 **Por que `JSON.stringify`?** Pela rede só viaja **texto**. Seu objeto `{ titulo: 'Oi' }` é uma estrutura do JavaScript, não dá pra enviar "cru". O `JSON.stringify` vira a string `'{"titulo":"Oi"}'`, que o servidor sabe ler. É tipo escrever a encomenda numa etiqueta antes de despachar.

## Exemplo resolvido (comentado)

```js
function editar(id, novoTitulo) {
  $.ajax({
    url: API + '?id=' + id,                                 // 1. qual tarefa
    method: 'PUT',                                          //    ação: atualizar
    contentType: 'application/json',                        // 2. "vou mandar JSON"
    data: JSON.stringify({ aluno_id: ALUNO_ID, titulo: novoTitulo })  //    objeto → texto JSON
  })
  .done(function () { listar(); })                          // recarrega pra ver a mudança
  .fail(function (xhr) { alert('Falha ao editar (' + xhr.status + ')'); });
}
```

> ⚠️ **Os dois esquecimentos clássicos do PUT:** faltar o `contentType: 'application/json'` **ou** o `JSON.stringify`. Sem os dois juntos, a API não entende o corpo e dá erro. Decore essa dupla.

### Como pedir o texto novo ao usuário: `prompt()`
`prompt('pergunta', 'valor inicial')` abre uma caixinha do navegador e **devolve** o que a pessoa digitou (ou `null` se ela cancelar).

### Botões dentro de cada tarefa (guardando o id)
Cada tarefa tem o seu próprio botão. O truque é **criar o botão e já ligar o clique dentro do `$.each`**, aproveitando que ali a gente tem o `t` (a tarefa daquela linha) com o `t.id`:
```js
$.each(tarefas, function (i, t) {
  var $li = $('<li>').text(t.titulo);
  $('<button>').text('✏️').on('click', function () {
    var novo = prompt('Novo título:', t.titulo);          // t.id e t.titulo são "lembrados" aqui
    if (novo && novo.trim() !== '') editar(t.id, novo.trim());
  }).appendTo($li);
  $li.appendTo('#lista');
});
```

# Parte 3 — Marcar como feito (PUT no campo `feito`)

## Explicação

"Feito" não é nada de especial: é só um **campo** da tarefa, que vale `0` (a fazer) ou `1` (concluída). Então marcar uma tarefa é só um **PUT que muda esse campo** — você já sabe fazer PUT! A única diferença é que, em vez de mandar `titulo`, você manda `feito`.

Lembra que a API atualiza **só o que você envia**? Então pra marcar é só mandar o `feito`, sem mexer no título:

```js
data: JSON.stringify({ aluno_id: ALUNO_ID, feito: 1 })   // só muda o "feito"
```

Pra interface, o ideal é um **checkbox** em cada tarefa:
- `.prop('checked', t.feito == 1)` → já deixa marcado se a tarefa estiver feita.
- o evento **`change`** dispara quando o usuário marca/desmarca.
- dentro dele, **`this.checked`** é `true` (marcou) ou `false` (desmarcou).

## Exemplo resolvido (comentado)

```js
function marcar(id, feito) {
  $.ajax({
    url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
    data: JSON.stringify({ aluno_id: ALUNO_ID, feito: feito ? 1 : 0 })  // true→1, false→0
  }).done(listar);
}

// ...dentro do $.each, um checkbox por tarefa:
$('<input type="checkbox">')
  .prop('checked', t.feito == 1)                          // já vem marcado se feito
  .on('change', function () { marcar(t.id, this.checked); })  // ao mudar, salva
  .appendTo($li);
```

# Parte 4 — Apagar: **DELETE**

## Explicação

**DELETE** remove a tarefa de vez. É o método mais simples: nossa API só quer o **id** e o **aluno_id** na URL — não precisa de corpo, nem de JSON.

```js
function apagar(id) {
  $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' })
    .done(function () { listar(); })
    .fail(function (xhr) { alert('Não consegui apagar (' + xhr.status + ')'); });
}
```

> ⚠️ **Apagar é irreversível — sempre confirme antes.** O `confirm('Apagar?')` abre uma caixinha de OK/Cancelar e **devolve `true`** se a pessoa clicar OK. Só apague se ela confirmar:
> ```js
> if (confirm('Apagar esta tarefa?')) apagar(t.id);
> ```

### Toque de classe: sumir com animação
O **`.fadeOut(tempo, função)`** faz o elemento desaparecer suavemente e, **quando a animação acaba**, roda a função que você passar. Assim dá pra "ver" a tarefa sumir antes de recarregar:
```js
$li.fadeOut(300, function () { listar(); });   // some em 0,3s e SÓ DEPOIS recarrega
```

# Parte 5 — Organizando o código

## Explicação

Repare que até agora, em cada exercício, você reescreveu as mesmas linhas de `$.ajax` várias vezes. Quando o app cresce, isso vira bagunça e dá erro fácil. A solução profissional é **separar dois mundos**:

- **falar com o servidor** (a "API") — as funções que fazem GET/POST/PUT/DELETE.
- **mexer na tela** (a "UI") — as funções que desenham os `<li>`.

A gente junta todas as chamadas ao servidor num **objeto** chamado `Tarefas`. Aí, no resto do código, em vez de repetir `$.ajax({...})`, você só escreve `Tarefas.criar(...)`, `Tarefas.editar(...)`. Fica curto e legível.

## Exemplo resolvido (comentado)

```js
var Tarefas = {
  listar: function ()       { return $.getJSON(API + '?aluno_id=' + ALUNO_ID); },
  criar:  function (titulo) { return $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }); },
  editar: function (id, dados) {
    return $.ajax({ url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
                    data: JSON.stringify($.extend({ aluno_id: ALUNO_ID }, dados)) });
  },
  apagar: function (id) {
    return $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' });
  }
};

// agora o uso fica limpinho:
Tarefas.criar('Estudar').done(recarregar);
Tarefas.editar(7, { feito: 1 }).done(recarregar);
Tarefas.editar(7, { titulo: 'Novo nome' }).done(recarregar);
Tarefas.apagar(7).done(recarregar);
```

> 🧩 **O truque do `$.extend`.** `$.extend({ aluno_id: ALUNO_ID }, dados)` **junta** dois objetos num só. Se `dados` for `{ feito: 1 }`, o resultado é `{ aluno_id: ..., feito: 1 }`. Por isso o **mesmo** `editar` serve tanto pra mudar o título quanto o "feito" — você só passa o que quer mudar.

# 🏆 Projeto final: **Painel de Missões** — `lab24/app.html`

## A ideia

Este é o entregável que junta **tudo** do semestre: criar, listar, marcar, editar e apagar — o CRUD completo, num app só. O HTML e o esqueleto do JS já vêm prontos; seu trabalho é **completar os 5 trechos `// ✏️`**. Cada um corresponde a algo que você já praticou nas Partes 2, 3 e 4.

**Checklist:**
- [ ] **Listar** ao abrir (com "Carregando..." e mensagem de lista vazia).
- [ ] **Criar** por formulário (preventDefault + não-vazio + limpa campo).
- [ ] **Marcar/desmarcar** feito (checkbox → PUT), riscando o texto.
- [ ] **Editar** o título (✏️ → PUT).
- [ ] **Apagar** com confirmação e animação (🗑️ → DELETE).
- [ ] Contador **"X de N concluídas"** sempre atualizado.
- [ ] Erro avisa na tela (`.fail`), nada trava calado.

**HTML + esqueleto:**
```html
<!DOCTYPE html>
<html lang="pt-br"><head><meta charset="utf-8"><title>Painel de Missões</title>
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<style>
  body{font-family:system-ui;max-width:600px;margin:40px auto}
  li{padding:6px} .feito{text-decoration:line-through;color:#999} .erro{border:2px solid #c0392b}
</style></head><body>
  <h1>🎯 Painel de Missões</h1>
  <form id="form"><input id="titulo" placeholder="Nova missão" autocomplete="off"><button>Adicionar</button></form>
  <h3 id="contador"></h3>
  <ul id="lista"></ul>
  <script>
    var API = 'https://curso.chr.eti.br/ajax/api.php';
    var ALUNO_ID = localStorage.getItem('aluno_id');

    var Tarefas = {
      listar: function ()       { return $.getJSON(API + '?aluno_id=' + ALUNO_ID); },
      criar:  function (titulo) { return $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }); },
      editar: function (id, d)  { return $.ajax({ url: API + '?id=' + id, method: 'PUT',
                    contentType: 'application/json', data: JSON.stringify($.extend({ aluno_id: ALUNO_ID }, d)) }); },
      apagar: function (id)     { return $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' }); }
    };

    function render(tarefas) {
      $('#lista').empty();
      if (tarefas.length === 0) { $('#lista').html('<p>Nenhuma missão 🎉</p>'); $('#contador').text(''); return; }
      var feitas = 0;
      $.each(tarefas, function (i, t) {
        if (t.feito == 1) feitas++;
        var $li = $('<li>');
        // ✏️ 1) checkbox: marcado se t.feito==1; no change → Tarefas.editar(t.id,{feito:...}).done(recarregar)
        // ✏️ 2) <span> com o título, riscado (classe 'feito') se t.feito==1
        // ✏️ 3) botão ✏️ → prompt → Tarefas.editar(t.id,{titulo:...}).done(recarregar)
        // ✏️ 4) botão 🗑️ → confirm → Tarefas.apagar(t.id).done(function(){ $li.fadeOut(300, recarregar); })
        $li.appendTo('#lista');
      });
      $('#contador').text(feitas + ' de ' + tarefas.length + ' concluídas');
    }

    function recarregar() {
      $('#lista').html('Carregando...');
      Tarefas.listar().done(render).fail(function () { $('#lista').html('Erro 😬'); });
    }

    $(function () {
      $('#form').on('submit', function (e) {
        e.preventDefault();
        var t = $('#titulo').val().trim();
        if (!t) { $('#titulo').addClass('erro').focus(); return; }
        $('#titulo').removeClass('erro');
        // ✏️ 5) Tarefas.criar(t) → no .done: limpa campo, foca, recarrega
      });
      recarregar();
    });
  </script>
</body></html>
```
**Resultado esperado:** um app completo onde você cria, marca, edita e apaga missões — e tudo fica salvo no servidor de verdade. 🏁

# 🧠 Cola — o CRUD inteiro

```js
// CREATE (criar)
$.post(API, { aluno_id: ALUNO_ID, titulo: t });
// READ (ler)
$.getJSON(API + '?aluno_id=' + ALUNO_ID);
// UPDATE (editar / marcar)
$.ajax({ url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
         data: JSON.stringify({ aluno_id: ALUNO_ID, titulo: t, feito: 1 }) });
// DELETE (apagar)
$.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' });
```

**Saiu daqui sabendo fazer um CRUD completo com jQuery + AJAX:** criar, listar, editar, marcar e apagar dados num servidor real, com código organizado e erros tratados. Esse é o **core do jQuery no mundo real**. 🏁🚀
