## A.1 — O motor completo: `$.ajax`

`$.getJSON` e `$.post` são **atalhos**. Por baixo, ambos usam o **`$.ajax`** — o motor completo, onde **você escolhe o método** (GET, POST, **PUT**, **DELETE**). Pra editar e apagar a gente precisa dele.

```js
$.ajax({
  url: API + '?recurso=matriculas&id=7',  // onde + qual registro
  method: 'PUT',                          // a ação
  contentType: 'application/json',        // "estou mandando JSON"
  data: JSON.stringify({ nome: 'Ana' })   // objeto vira texto JSON
})
.done(function (r) { ... })
.fail(function (xhr) { ... });
```

> 🧠 **`JSON.stringify`:** pela rede só viaja **texto**. Seu objeto `{nome:'Ana'}` é uma estrutura do JavaScript; o `JSON.stringify` transforma em `'{"nome":"Ana"}'`, que o servidor entende. Pra PUT, sempre a dupla **`contentType: 'application/json'` + `JSON.stringify`**.

## A.2 — Update: editar com PUT

Editar atualiza um registro que **já existe** — por isso precisa do **id na URL**. A API atualiza **só os campos que você mandar**.

```js
function editar(id, dados) {
  return $.ajax({
    url: API + '?recurso=matriculas&id=' + id,
    method: 'PUT',
    contentType: 'application/json',
    data: JSON.stringify(dados)
  });
}
// uso: editar(7, { nome: 'Ana Maria', ativo: 0 }).done(carregar);
```

## A.3 — O "Salvar inteligente" (o coração da aula)

No nosso formulário tem um campo escondido `#id`. A regra é simples e poderosa:

- **`#id` vazio** → é registro novo → **POST** (Create)
- **`#id` preenchido** → registro existente → **PUT** (Update)

Um botão **Salvar** só, que faz a coisa certa:
```js
function salvar() {
  var dados = {
    nome:  $('#nome').val().trim(),
    cpf:   $('#cpf').val().trim(),
    curso: $('#curso').val().trim(),
    email: $('#email').val().trim(),
    ativo: $('#ativo').is(':checked') ? 1 : 0
  };
  var id = $('#id').val();
  var req = id
    ? editar(id, dados)                              // tem id → edita
    : $.post(API + '?recurso=matriculas', dados);    // sem id → cria

  req.done(function () { carregar(); aviso('Salvo ✅'); })
     .fail(function (xhr) { aviso('Erro ' + xhr.status + ' 😕'); });
}
```
> 💡 É exatamente assim que funciona qualquer tela de cadastro de sistema real: o mesmo formulário cria e edita, decidindo pelo id.

## A.4 — Delete: apagar com DELETE

Apagar remove de vez — só precisa do **id na URL**, sem corpo:
```js
function apagar(id) {
  return $.ajax({ url: API + '?recurso=matriculas&id=' + id, method: 'DELETE' });
}
```

> ⚠️ **Apagar é irreversível — sempre confirme.** `confirm('Apagar?')` devolve `true` se clicar OK:
> ```js
> if (confirm('Apagar esta matrícula?')) {
>   apagar(id).done(function () { carregar(); });
> }
> ```

No app de formulário, "Apagar" remove o registro que está na tela e depois mostra outro (ou limpa, se acabou):
```js
$('#apagar').on('click', function () {
  var id = $('#id').val();
  if (!id) return;                                   // nada selecionado
  if (!confirm('Apagar esta matrícula?')) return;
  apagar(id).done(function () {
    if (pos > 0) pos--;                              // volta um, se der
    carregar();                                      // recarrega e mostra
  }).fail(function (xhr) { aviso('Erro ' + xhr.status); });
});
```

## A.5 — Animação ao apagar (UX)

Some suave antes de sumir de fato. O `.fadeOut(tempo, função)` roda a função **quando a animação acaba**:
```js
$linha.fadeOut(300, function () { apagar(id).done(carregar); });
```

## A.6 — Boas práticas: a camada `Matriculas` completa

Agora com as 4 operações, junte tudo num objeto só (servidor separado da tela). Repare que cada função **retorna a promise** — por isso dá pra encadear `.done/.fail`:
```js
var Matriculas = {
  listar: function ()       { return $.getJSON(API + '?recurso=matriculas'); },
  criar:  function (dados)  { return $.post(API + '?recurso=matriculas', dados); },
  editar: function (id, d)  { return $.ajax({ url: API + '?recurso=matriculas&id=' + id,
                                method: 'PUT', contentType: 'application/json',
                                data: JSON.stringify(d) }); },
  apagar: function (id)     { return $.ajax({ url: API + '?recurso=matriculas&id=' + id,
                                method: 'DELETE' }); }
};
```
Mais boas práticas que continuam valendo: **cache de seletor**, **`.text()` pra dado de usuário** (anti-XSS), **tratar erro sempre**, **`.always` pra religar botões**.

## 🏆 Bloco 4 — Desafio: Agenda editável (recurso `agenda`)

Continue a agenda da aula passada (grade Seg→Dom, 06:00→00:00). Lá você fez **hidratar** e **criar**. Agora: **editar** e **apagar** células — fechando o CRUD na segunda tela.

> Reaproveite o `montarGrade()` e o `celula(dia,hora)` da Aula 3. Cada célula precisa "lembrar" o `id` da tarefa que está nela — guarde com `.data('id', t.id)` ao hidratar.

### `desafio1-agenda-editar.html` — ✏️ Clicar na célula CHEIA e editar
**O que fazer:** ao hidratar, guarde o id na célula (`celula(t.dia,t.hora).text(t.texto).data('id', t.id)`). Ao **clicar numa célula que já tem texto**, abra o `<input>` **já preenchido** (animação); ao sair/Enter, faça **PUT** (editar) usando o id guardado.
**💡 Dica (clique unificado cria-ou-edita):**
```js
$('#grade').on('click', 'td', function () {
  var $td = $(this);
  if ($td.find('input').length) return;
  var dia = $td.data('dia'), hora = $td.data('hora'), id = $td.data('id');
  var atual = $td.text();
  var $inp = $('<input>').val(atual).css('width','80px').hide();
  $td.empty().append($inp);
  $inp.fadeIn(150).focus();
  function salvar() {
    var texto = $inp.val().trim();
    if (texto === '') { $td.empty().removeData('id'); return; }   // (apagar fica no próximo)
    var req = id
      ? $.ajax({ url: API + '?recurso=agenda&id=' + id, method: 'PUT',
                 contentType: 'application/json', data: JSON.stringify({ texto: texto }) })
      : $.post(API + '?recurso=agenda', { dia: dia, hora: hora, texto: texto });
    req.done(function (r) { $td.text(texto); if (r && r.id) $td.data('id', r.id); })
       .fail(function () { alert('Erro ao salvar'); });
  }
  $inp.on('blur', salvar);
  $inp.on('keydown', function (e) { if (e.key === 'Enter') $inp.blur(); });
});
```
**Resultado esperado:** clicar numa célula cheia edita o texto; numa vazia, cria. Tudo salvo no servidor.
