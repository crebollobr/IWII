# Parte 1 — O comando completo: `$.ajax`

`$.getJSON` e `$.post` (da aula passada) são **atalhos**. Por baixo, os dois chamam o mesmo motor: **`$.ajax`**. Para **editar** e **apagar** a gente precisa do motor completo, porque ele deixa escolher o **método** (GET, POST, **PUT**, **DELETE**) e o **formato** dos dados.

**Exemplo resolvido** (listar usando `$.ajax`, igual ao `$.getJSON`):
```js
function listar() {
  $.ajax({
    url: API + '?aluno_id=' + ALUNO_ID,
    method: 'GET',
    dataType: 'json'                 // "me devolva já convertido de JSON"
  })
  .done(function (tarefas) {
    $('#lista').empty();
    $.each(tarefas, function (i, t) {
      $('<li>').text('[' + t.id + '] ' + t.titulo).appendTo('#lista');
    });
  })
  .fail(function (xhr) { alert('Erro ao listar (' + xhr.status + ')'); });
}
```

> 🧠 **Tradução:** "vá na `url`, com esse `method`, e me devolva `json`." Repare que hoje a gente vai mostrar o **id** de cada tarefa — vamos precisar dele o tempo todo (pra dizer ao servidor *qual* editar/apagar).

# Parte 2 — Editar uma tarefa: **PUT**

PUT atualiza algo que **já existe**. As regras da nossa API:
- o **id** vai na URL: `api.php?id=7`
- o corpo vai como **JSON** → precisa de `contentType: 'application/json'` **e** `JSON.stringify(...)`
- o corpo inclui o `aluno_id` e o que mudou (a API atualiza **só o que você mandar**).

**Exemplo resolvido** (mudar o título da tarefa de id 7):
```js
function editar(id, novoTitulo) {
  $.ajax({
    url: API + '?id=' + id,
    method: 'PUT',
    contentType: 'application/json',
    data: JSON.stringify({ aluno_id: ALUNO_ID, titulo: novoTitulo })
  })
  .done(function () { listar(); })
  .fail(function (xhr) { alert('Falha ao editar (' + xhr.status + ')'); });
}
```

> ⚠️ **Os dois esquecimentos clássicos do PUT:** faltou o `contentType: 'application/json'` ou faltou o `JSON.stringify`. Sem os dois, a API não entende o corpo. Decore a dupla.

### Pegar o novo texto do usuário — `prompt()`
`prompt('pergunta', 'valor inicial')` abre uma caixinha e devolve o que a pessoa digitou.

### Botões dentro de cada `<li>` (com o id "guardado")
Como cada tarefa tem o seu botão, a gente **cria o botão e já liga o clique** dentro do `$.each`, usando o `t` daquela tarefa:
```js
$.each(tarefas, function (i, t) {
  var $li = $('<li>').text(t.titulo);
  $('<button>').text('✏️').on('click', function () {
    var novo = prompt('Novo título:', t.titulo);
    if (novo && novo.trim() !== '') editar(t.id, novo.trim());
  }).appendTo($li);
  $li.appendTo('#lista');
});
```

# Parte 3 — Marcar como feito (PUT no campo `feito`)

"Feito" é só um campo (`feito`: 0 ou 1). Marcar = um PUT que muda **só** esse campo. `.prop('checked', ...)` deixa um checkbox marcado; dentro do evento, `this.checked` diz se ele está marcado (`true`/`false`).

**Exemplo resolvido:**
```js
function marcar(id, feito) {
  $.ajax({
    url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
    data: JSON.stringify({ aluno_id: ALUNO_ID, feito: feito ? 1 : 0 })
  }).done(listar);
}
// ...dentro do $.each, criando o checkbox de cada tarefa:
$('<input type="checkbox">')
  .prop('checked', t.feito == 1)
  .on('change', function () { marcar(t.id, this.checked); })
  .appendTo($li);
```

# Parte 4 — Apagar: **DELETE**

DELETE remove de vez. A nossa API quer **id e aluno_id na URL** (sem corpo):
```js
function apagar(id) {
  $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' })
    .done(function () { listar(); })
    .fail(function (xhr) { alert('Não consegui apagar (' + xhr.status + ')'); });
}
```

> ⚠️ **Apagar é destrutivo — sempre confirme.** `confirm('Apagar?')` devolve `true` se a pessoa clicar OK.

```js
$('<button>').text('🗑️').on('click', function () {
  if (confirm('Apagar esta tarefa?')) apagar(t.id);
}).appendTo($li);
```

### Sumir com animação antes de recarregar — `.fadeOut(tempo, callback)`
O `.fadeOut` aceita uma função pra rodar **quando a animação acabar**:
```js
$li.fadeOut(300, function () { listar(); });   // some suave e SÓ DEPOIS recarrega
```

# Parte 5 — Organizando o código

Quando o app cresce, misturar "falar com a API" e "mexer na tela" vira bagunça. Separe em **duas caixinhas**: um objeto `Tarefas` (só servidor) e funções de tela.

**Exemplo resolvido:**
```js
var Tarefas = {
  listar: function ()       { return $.getJSON(API + '?aluno_id=' + ALUNO_ID); },
  criar:  function (titulo) { return $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }); },
  editar: function (id, dados) {
    return $.ajax({ url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
                    data: JSON.stringify($.extend({ aluno_id: ALUNO_ID }, dados)) });
  },
  apagar: function (id) {
    return $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' });
  }
};
// uso fica limpo:
Tarefas.criar('Estudar').done(recarregar);
Tarefas.editar(7, { feito: 1 }).done(recarregar);
Tarefas.apagar(7).done(recarregar);
```
> `$.extend({aluno_id: ALUNO_ID}, dados)` junta o `aluno_id` com o que você quer mudar (`{titulo:...}` ou `{feito:...}`). Assim o mesmo `editar` serve pra título e pra feito.

**HTML + esqueleto:**
```html
<!DOCTYPE html>
<html lang="pt-br"><head><meta charset="utf-8"><title>Painel de Missões</title>
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<style>
  body{font-family:system-ui;max-width:600px;margin:40px auto}
  li{padding:6px} .feito{text-decoration:line-through;color:#999} .erro{border:2px solid #c0392b}
</style></head><body>
  <h1>🎯 Painel de Missões</h1>
  <form id="form"><input id="titulo" placeholder="Nova missão" autocomplete="off"><button>Adicionar</button></form>
  <h3 id="contador"></h3>
  <ul id="lista"></ul>
  <script>
    var API = 'https://curso.chr.eti.br/ajax/api.php';
    var ALUNO_ID = localStorage.getItem('aluno_id');

    var Tarefas = {
      listar: function ()       { return $.getJSON(API + '?aluno_id=' + ALUNO_ID); },
      criar:  function (titulo) { return $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }); },
      editar: function (id, d)  { return $.ajax({ url: API + '?id=' + id, method: 'PUT',
                    contentType: 'application/json', data: JSON.stringify($.extend({ aluno_id: ALUNO_ID }, d)) }); },
      apagar: function (id)     { return $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' }); }
    };

    function render(tarefas) {
      $('#lista').empty();
      if (tarefas.length === 0) { $('#lista').html('<p>Nenhuma missão 🎉</p>'); $('#contador').text(''); return; }
      var feitas = 0;
      $.each(tarefas, function (i, t) {
        if (t.feito == 1) feitas++;
        var $li = $('<li>');
        // ✏️ 1) checkbox: marcado se t.feito==1; no change → Tarefas.editar(t.id,{feito:...}).done(recarregar)
        // ✏️ 2) <span> com o título, riscado (classe 'feito') se t.feito==1
        // ✏️ 3) botão ✏️ → prompt → Tarefas.editar(t.id,{titulo:...}).done(recarregar)
        // ✏️ 4) botão 🗑️ → confirm → Tarefas.apagar(t.id).done(() => $li.fadeOut(300, recarregar))
        $li.appendTo('#lista');
      });
      $('#contador').text(feitas + ' de ' + tarefas.length + ' concluídas');
    }

    function recarregar() {
      $('#lista').html('Carregando...');
      Tarefas.listar().done(render).fail(function () { $('#lista').html('Erro 😬'); });
    }

    $(function () {
      $('#form').on('submit', function (e) {
        e.preventDefault();
        var t = $('#titulo').val().trim();
        if (!t) { $('#titulo').addClass('erro').focus(); return; }
        $('#titulo').removeClass('erro');
        // ✏️ 5) Tarefas.criar(t) → no .done: limpa campo, foca, recarrega
      });
      recarregar();
    });
  </script>
</body></html>
```
**Resultado esperado:** um app completo onde você cria, marca, edita e apaga missões — e tudo fica salvo no servidor de verdade. 🏁

# 🧠 Cola — o CRUD inteiro

```js
// CREATE
$.post(API, { aluno_id: ALUNO_ID, titulo: t });
// READ
$.getJSON(API + '?aluno_id=' + ALUNO_ID);
// UPDATE (editar / marcar)
$.ajax({ url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
         data: JSON.stringify({ aluno_id: ALUNO_ID, titulo: t, feito: 1 }) });
// DELETE
$.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' });
```

**Saiu daqui sabendo fazer um CRUD completo com jQuery + AJAX:** criar, listar, editar, marcar e apagar dados num servidor real, com código organizado e erros tratados. Esse é o **core do jQuery no mundo real**. 🏁🚀
