## A.1 — O comando completo: `$.ajax`

Na Aula 3 você usou `$.getJSON` (ler) e `$.post` (criar). O que talvez não saiba: os dois são só **atalhos**. Por baixo, ambos chamam o **mesmo motor**, o **`$.ajax`** — já configurado pro caso comum.

> 🚗 **Analogia do câmbio.** `$.getJSON` é automático: simples, faz o trabalho. `$.ajax` é manual: dá mais trabalho, mas **você escolhe a marcha**. Pra editar (PUT) e apagar (DELETE) a gente **precisa** escolher a marcha — porque usam "métodos" que o atalho não oferece.

Todo pedido HTTP tem um **método** (o tipo de ação): **GET** (ler), **POST** (criar), **PUT** (atualizar), **DELETE** (apagar). O `$.ajax` recebe um objeto descrevendo o pedido:

```js
$.ajax({
  url: API + '?aluno_id=' + ALUNO_ID,  // pra onde vai
  method: 'GET',                       // qual ação (GET/POST/PUT/DELETE)
  dataType: 'json'                     // "me devolva já convertido de JSON"
})
.done(function (resposta) { /* deu certo */ })
.fail(function (xhr)      { /* deu erro  */ });
```

**Exemplo resolvido — listar mostrando o `id`** (vamos precisar dele o tempo todo hoje, pra dizer *qual* tarefa editar/apagar):
```js
function listar() {
  $.ajax({ url: API + '?aluno_id=' + ALUNO_ID, method: 'GET', dataType: 'json' })
    .done(function (tarefas) {
      $('#lista').empty();
      $.each(tarefas, function (i, t) {
        $('<li>').text('[' + t.id + '] ' + t.titulo).appendTo('#lista');  // mostra o id
      });
    })
    .fail(function (xhr) { alert('Erro ao listar (' + xhr.status + ')'); });
}
```

## A.2 — Editar: **PUT**

**PUT** atualiza algo que **já existe**. Diferente do POST (cria do zero), o PUT precisa dizer **qual** registro mexer. Três regras na nossa API:

1. **Qual** tarefa? O **id** vai na URL: `api.php?id=7`.
2. **Como** mandar os dados? Como **JSON** no corpo. Isso exige duas coisas juntas:
   - `contentType: 'application/json'` → avisa "estou mandando JSON".
   - `JSON.stringify({...})` → transforma seu objeto JavaScript em **texto** JSON pra viajar.
3. **O que** mandar? O `aluno_id` (prova que é sua) + o campo que mudou. A API atualiza **só o que você enviar**.

> 🧠 **Por que `JSON.stringify`?** Pela rede só viaja **texto**. Seu objeto `{ titulo: 'Oi' }` é uma estrutura do JavaScript; o `JSON.stringify` vira a string `'{"titulo":"Oi"}'`, que o servidor sabe ler. É como escrever a etiqueta antes de despachar a encomenda.

**Exemplo resolvido:**
```js
function editar(id, novoTitulo) {
  $.ajax({
    url: API + '?id=' + id,                                          // qual tarefa
    method: 'PUT',                                                   // ação: atualizar
    contentType: 'application/json',                                 // "vou mandar JSON"
    data: JSON.stringify({ aluno_id: ALUNO_ID, titulo: novoTitulo }) // objeto → texto
  })
  .done(function () { listar(); })
  .fail(function (xhr) { alert('Falha ao editar (' + xhr.status + ')'); });
}
```

> ⚠️ **Os dois esquecimentos clássicos:** faltar o `contentType` **ou** o `JSON.stringify`. Sem os dois juntos, a API não entende. Decore a dupla.

**Como pedir o texto novo:** `prompt('pergunta', 'valor inicial')` abre uma caixinha e **devolve** o que a pessoa digitou (ou `null` se cancelar).

**Botões dentro de cada tarefa (guardando o id):** crie o botão e já ligue o clique **dentro do `$.each`**, aproveitando o `t` daquela linha (com `t.id`):
```js
$.each(tarefas, function (i, t) {
  var $li = $('<li>').text(t.titulo);
  $('<button>').text('✏️').on('click', function () {
    var novo = prompt('Novo título:', t.titulo);          // t.id é "lembrado" aqui
    if (novo && novo.trim() !== '') editar(t.id, novo.trim());
  }).appendTo($li);
  $li.appendTo('#lista');
});
```

## A.3 — Marcar como feito (PUT no campo `feito`)

"Feito" não é nada de especial: é só um **campo** que vale `0` (a fazer) ou `1` (concluída). Então marcar é só um **PUT que muda esse campo** — você já sabe fazer PUT! A diferença: em vez de `titulo`, manda `feito`. Como a API atualiza **só o que você envia**, é só mandar o `feito`:

```js
data: JSON.stringify({ aluno_id: ALUNO_ID, feito: 1 })   // só muda o "feito"
```

Pra interface, um **checkbox** em cada tarefa:
- `.prop('checked', t.feito == 1)` → já vem marcado se a tarefa estiver feita.
- o evento **`change`** dispara quando o usuário marca/desmarca.
- dentro dele, **`this.checked`** é `true` (marcou) ou `false` (desmarcou).

**Exemplo resolvido:**
```js
function marcar(id, feito) {
  $.ajax({
    url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
    data: JSON.stringify({ aluno_id: ALUNO_ID, feito: feito ? 1 : 0 })  // true→1, false→0
  }).done(listar);
}

// ...dentro do $.each, um checkbox por tarefa:
$('<input type="checkbox">')
  .prop('checked', t.feito == 1)
  .on('change', function () { marcar(t.id, this.checked); })
  .appendTo($li);
```

## A.4 — Apagar: **DELETE**

**DELETE** remove de vez. É o mais simples: a API só quer o **id** e o **aluno_id** na URL — sem corpo, sem JSON.

```js
function apagar(id) {
  $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' })
    .done(function () { listar(); })
    .fail(function (xhr) { alert('Não consegui apagar (' + xhr.status + ')'); });
}
```

> ⚠️ **Apagar é irreversível — sempre confirme antes.** `confirm('Apagar?')` abre OK/Cancelar e **devolve `true`** se clicar OK:
> ```js
> if (confirm('Apagar esta tarefa?')) apagar(t.id);
> ```

**Toque de classe — sumir com animação:** `.fadeOut(tempo, função)` faz o elemento desaparecer suave e, **quando a animação acaba**, roda a função:
```js
$li.fadeOut(300, function () { listar(); });   // some em 0,3s e SÓ DEPOIS recarrega
```

## A.5 — Organizando o código

Repare que você reescreveu as mesmas linhas de `$.ajax` várias vezes. Quando o app cresce, isso vira bagunça. A solução é **separar dois mundos**: **falar com o servidor** (a "API") e **mexer na tela** (a "UI"). Juntamos as chamadas num objeto `Tarefas`; no resto do código você só escreve `Tarefas.criar(...)`, `Tarefas.editar(...)`.

**Exemplo resolvido:**
```js
var Tarefas = {
  listar: function ()       { return $.getJSON(API + '?aluno_id=' + ALUNO_ID); },
  criar:  function (titulo) { return $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }); },
  editar: function (id, dados) {
    return $.ajax({ url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
                    data: JSON.stringify($.extend({ aluno_id: ALUNO_ID }, dados)) });
  },
  apagar: function (id) {
    return $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' });
  }
};
// uso fica limpinho:
Tarefas.criar('Estudar').done(recarregar);
Tarefas.editar(7, { feito: 1 }).done(recarregar);
Tarefas.editar(7, { titulo: 'Novo nome' }).done(recarregar);
Tarefas.apagar(7).done(recarregar);
```

> 🧩 **O truque do `$.extend`.** `$.extend({ aluno_id: ALUNO_ID }, dados)` **junta** dois objetos. Se `dados` for `{ feito: 1 }`, vira `{ aluno_id: ..., feito: 1 }`. Por isso o **mesmo** `editar` serve pra título e pra feito — você só passa o que quer mudar.

</style></head><body>
  <h1>🎯 Painel de Missões</h1>
  <form id="form"><input id="titulo" placeholder="Nova missão" autocomplete="off"><button>Adicionar</button></form>
  <h3 id="contador"></h3>
  <ul id="lista"></ul>
  <script>
    var API = 'https://curso.chr.eti.br/ajax/api.php';
    var ALUNO_ID = localStorage.getItem('aluno_id');

    var Tarefas = {
      listar: function ()       { return $.getJSON(API + '?aluno_id=' + ALUNO_ID); },
      criar:  function (titulo) { return $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }); },
      editar: function (id, d)  { return $.ajax({ url: API + '?id=' + id, method: 'PUT',
                    contentType: 'application/json', data: JSON.stringify($.extend({ aluno_id: ALUNO_ID }, d)) }); },
      apagar: function (id)     { return $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' }); }
    };

    function render(tarefas) {
      $('#lista').empty();
      if (tarefas.length === 0) { $('#lista').html('<p>Nenhuma missão 🎉</p>'); $('#contador').text(''); return; }
      var feitas = 0;
      $.each(tarefas, function (i, t) {
        if (t.feito == 1) feitas++;
        var $li = $('<li>');
        // ✏️ 1) checkbox: marcado se t.feito==1; no change → Tarefas.editar(t.id,{feito:...}).done(recarregar)
        // ✏️ 2) <span> com o título, riscado (classe 'feito') se t.feito==1
        // ✏️ 3) botão ✏️ → prompt → Tarefas.editar(t.id,{titulo:...}).done(recarregar)
        // ✏️ 4) botão 🗑️ → confirm → Tarefas.apagar(t.id).done(function(){ $li.fadeOut(300, recarregar); })
        $li.appendTo('#lista');
      });
      $('#contador').text(feitas + ' de ' + tarefas.length + ' concluídas');
    }

    function recarregar() {
      $('#lista').html('Carregando...');
      Tarefas.listar().done(render).fail(function () { $('#lista').html('Erro 😬'); });
    }

    $(function () {
      $('#form').on('submit', function (e) {
        e.preventDefault();
        var t = $('#titulo').val().trim();
        if (!t) { $('#titulo').addClass('erro').focus(); return; }
        $('#titulo').removeClass('erro');
        // ✏️ 5) Tarefas.criar(t) → no .done: limpa campo, foca, recarrega
      });
      recarregar();
    });
  </script>
</body></html>
