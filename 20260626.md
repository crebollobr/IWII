## A explicação rápida (o que muda hoje)

Pra **editar** e **apagar** a gente precisa do comando completo, o **`$.ajax`** — porque dá pra escolher o **método** (PUT, DELETE) e o **formato** dos dados.

**Editar / marcar — PUT** (manda JSON):
```js
$.ajax({
  url: API + '?id=' + id,
  method: 'PUT',
  contentType: 'application/json',                       // "estou mandando JSON"
  data: JSON.stringify({ aluno_id: ALUNO_ID, titulo: novoTitulo })
}).done(listar);
```

**Apagar — DELETE** (id + aluno_id na URL, sem corpo):
```js
$.ajax({
  url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID,
  method: 'DELETE'
}).done(listar);
```

> ⚠️ **Os dois esquecimentos clássicos do PUT:** faltou `contentType: 'application/json'` ou faltou `JSON.stringify`. Sem os dois, a API não entende o corpo. Decore a dupla.
> 🧠 A API faz **atualização parcial**: no PUT você manda **só o que mudou** (`titulo` OU `feito`), sempre junto do `aluno_id`.

**Delegação de evento** (a lista nasce e morre o tempo todo, então ligue o clique no container fixo):
```js
$('#lista').on('click', '.btn-apagar', function () {
  var id = $(this).data('id');          // o id veio do data-id do botão
  if (confirm('Apagar?')) apagar(id);
});
```
E ao montar o `<li>`, guarde o id: `$('<button>').addClass('btn-apagar').attr('data-id', t.id)`.

**É isso. Agora é com vocês.** ⬇️

## 🧱 Organização

- **`ex15-organizado.html`** 🧰 — separe "falar com a API" de "mexer na tela":
  ```js
  var Tarefas = {
    listar: function ()        { return $.getJSON(API + '?aluno_id=' + ALUNO_ID); },
    criar:  function (titulo)  { return $.post(API, { aluno_id: ALUNO_ID, titulo: titulo }); },
    editar: function (id, dados) {
      return $.ajax({ url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
        data: JSON.stringify($.extend({ aluno_id: ALUNO_ID }, dados)) });
    },
    apagar: function (id) {
      return $.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' });
    }
  };
  // uso: Tarefas.criar(t).done(recarregar);  Tarefas.editar(id, {feito:1}).done(recarregar);
  ```

## 🏆 Projeto final: **Painel de Missões** — `lab24/app.html`

O entregável da aula. Junta tudo do semestre de jQuery + AJAX.

- [ ] **Listar** ao abrir (com "Carregando..." e mensagem de lista vazia).
- [ ] **Criar** por formulário (preventDefault + validação + limpa campo).
- [ ] **Marcar/desmarcar** feito (checkbox → PUT), riscando o texto.
- [ ] **Editar** o título (✏️ → PUT).
- [ ] **Apagar** com confirmação e animação (🗑️ → DELETE).
- [ ] Contador **"X de N concluídas"** sempre atualizado.
- [ ] Código separado em **API (`Tarefas`)** e **UI (`render`)**.
- [ ] Todo erro avisa na tela (`.fail`), nada trava calado.

### Esqueleto pra começar
```js
$(function () {
  var $lista = $('#lista');

  function render(tarefas) {
    $lista.empty();
    if (tarefas.length === 0) { $lista.html('<p>Nenhuma missão 🎉</p>'); return; }
    var feitas = 0;
    $.each(tarefas, function (i, t) {
      if (t.feito == 1) feitas++;
      var $li = $('<li>');
      $('<input type="checkbox">').prop('checked', t.feito == 1)
        .on('change', function () {
          Tarefas.editar(t.id, { feito: this.checked ? 1 : 0 }).done(recarregar);
        }).appendTo($li);
      $('<span>').text(' ' + t.titulo).toggleClass('feito', t.feito == 1).appendTo($li);
      $('<button>').text('✏️').on('click', function () {
        var novo = prompt('Novo título:', t.titulo);
        if (novo && novo.trim()) Tarefas.editar(t.id, { titulo: novo.trim() }).done(recarregar);
      }).appendTo($li);
      $('<button>').text('🗑️').on('click', function () {
        if (confirm('Apagar?')) Tarefas.apagar(t.id).done(function () { $li.fadeOut(300, recarregar); });
      }).appendTo($li);
      $lista.append($li);
    });
    $('#contador').text(feitas + ' de ' + tarefas.length + ' concluídas');
  }

  function recarregar() { Tarefas.listar().done(render).fail(function () { $lista.html('Erro 😬'); }); }

  $('#form').on('submit', function (e) {
    e.preventDefault();
    var t = $('#titulo').val().trim();
    if (!t) { $('#titulo').addClass('erro').focus(); return; }
    $('#titulo').removeClass('erro');
    Tarefas.criar(t).done(function () { $('#titulo').val('').focus(); recarregar(); });
  });

  recarregar();
});
```

## 🧠 Cola — o CRUD inteiro

```js
// CREATE
$.post(API, { aluno_id: ALUNO_ID, titulo: t });
// READ
$.getJSON(API + '?aluno_id=' + ALUNO_ID);
// UPDATE (editar / marcar)
$.ajax({ url: API + '?id=' + id, method: 'PUT', contentType: 'application/json',
         data: JSON.stringify({ aluno_id: ALUNO_ID, titulo: t, feito: 1 }) });
// DELETE
$.ajax({ url: API + '?id=' + id + '&aluno_id=' + ALUNO_ID, method: 'DELETE' });
```

**Saiu daqui sabendo fazer um CRUD completo com jQuery + AJAX:** criar, listar, editar, marcar e apagar dados num servidor real, com código organizado e erros tratados. Esse é o **core do jQuery no mundo real** — a base de praticamente qualquer tela de sistema. 🏁🚀
